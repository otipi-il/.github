## Otipi: SMS, email and login codes for Israeli apps

One API for SMS login codes (OTP), SMS and transactional email to Israeli numbers (`+972`), with templates in Hebrew, Arabic, Russian and English. Free test mode with real delivery to your own phone.

| | |
| --- | --- |
| [otipi-node](https://github.com/otipi-il/otipi-node) | Node.js SDK (`npm install otipi`), Claude Code plugin, Cursor rules, Next.js and Supabase examples |
| [otipi-mcp](https://github.com/otipi-il/otipi-mcp) | MCP server for AI agents: `npx -y otipi-mcp` or hosted at `https://otipi.co.il/mcp` |
| [otipi-supabase](https://github.com/otipi-il/otipi-supabase) | Optional edge function for the Supabase Send SMS hook |
